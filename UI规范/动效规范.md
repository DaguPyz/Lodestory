# Lodestory · 统一动效规范

**版本：2.2 ｜ 日期：2026-10-25 ｜ 状态：运行代码已同步；跨平台客户端与完整性能验收待完成**

本规范细化[UI 设计规范](UI设计规范.md)的 MOT-01，适用于所有自绘界面、公共组件和插件贡献。核心原则是让界面状态清楚、内容位置稳定、反馈克制。动效只在确实有助于辨认浮层显隐或表面状态时使用；不得为了增加“灵动感”制造动作。

通用时长参数接入共享变量；时间线事件文字、主线与节点生长的专用时长由时间线插件私有变量提供。下文规则约束后续实现，当前验证范围与未完成事项见第 08、09 节。

## 01. 归属与接入

| 项目 | 约定 |
| --- | --- |
| 归属 | 公共时长变量由共享视觉基础定义；控件过渡归 `@lodestory/ui`；菜单、布局、工程树、文档标签和状态提示由各自插件呈现。无需新建动效插件。 |
| 协作 | 复用现有 UI、布局、文档与工作台公开能力。纯样式不新增服务 key；公共组件不读取其他插件的私有状态。 |
| 接入 | 页面与根包装通过 UI 服务登记，工作台内容通过布局服务登记，控件复用 `@lodestory/ui`。内置插件仍由 `appPlugins.ts` 显式装配。 |
| 生命周期 | 偏好与监听属于应用实例；布局呈现属于工作台；过渡资源属于对应组件。组件停止使用服务后再释放资源；初始化失败、停用和父级卸载都能完成清理。 |
| 验收 | 改变动效偏好、快速开合、关闭浮层、停用插件或替换主题／布局时，状态、焦点、编辑会话和用户内容仍然正确。 |

`src/plugin-core/` 不增加动效、页面或编辑器知识。SDK 仅承载确有需要的共享契约，不放 CSS、动画实例或组件实现。

## 02. 动效原则

### M-01｜内容保持稳定

- 输入、中文输入法合成、光标、选区、撤销重做、滚动、拖动、焦点、选值与结构调整立即响应。
- 页面导航、主题或密度切换、正文切换、搜索结果更新、保存状态变化不延迟、不播放装饰过渡。
- 不使用 `translate` 过渡／动画；缩放仅允许 M-02 的时间线事件文字悬停和主线生长例外，不带动节点、布局或命中区。
- 悬停不改变边框和阴影；阴影始终使用静态主题配方。普通悬停、按下和选中按 UI 规范改变配对表面与文字颜色，时间线事件文字悬停按 M-02 联动缩放；普通选中即时显示灰底；文字项不附加对勾、混合态显示短横，纯图标保持居中且不叠加标记；焦点使用独立的低饱和灰蓝边界。
- 不使用弹簧回弹、上浮、错误抖动、翻页、视差、扫光或品牌开场动画；逐项延迟仅允许打开时间线时的节点生长例外。自动循环仅允许 TXT 编辑器自绘光标的呼吸闪烁；减少动效时光标常亮。

### M-02｜只为必要反馈过渡

允许的动效限于同一主题下已验证可读的状态颜色变化、菜单和 Tooltip 等浮层的整体透明度变化、时间线事件文字悬停的轻微联动缩放、打开时间线时主线和节点的一次生长，以及 TXT 编辑器自绘光标的呼吸闪烁。普通状态颜色与浮层透明度统一使用 150ms；时间线事件文字缩放单独使用 500ms；有明确立即响应要求的状态仍为 0ms。浮层定位始终使用最终布局坐标，进入和退出都只改变 `opacity`。

时间线事件文字悬停时，主标题以 500ms 从 1 倍平滑放大至 1.2 倍，日期／时间偏移和摘要同步从 1 倍平滑放大至 1.05 倍；主标题下的短横线同时使用 `scaleX` 在 1 与 1.2 倍间变化，保持 1px 粗细。三层文字与短横线共用 `--ui-ease-enter` 的贝塞尔曲线 `cubic-bezier(.2, 0, 0, 1)`，放大与恢复各为500ms。各元素的基态与悬停态显式设置变换，过渡声明放在基态；按左右对齐固定文字组和短横线相同侧边缘。背景透明、颜色不变，不插值字号或行高，不改变节点、其他线条、布局占位和点击区域。仅支持悬停且画布活跃时启用，亮暗和自定义主题共用；系统或用户减少动效时维持原尺寸。此例外不适用于普通按钮、列表或时间线端点。

打开或切换至另一条时间线时，主线从视口左侧向右生长，持续 400ms，使用 `cubic-bezier(.2, 0, 0, 1)`；箭头显示在最终位置；主线完成后，刻度在700ms内从左向右依次由下往上生长，然后数字标签在500ms内从左向右由下往上显现；数字标签全部显现后，事件连接线按时间轴从左向右依次从主轴向外生长：上方连接线向上、下方连接线向下，连接线依次生长的阶段持续 1600ms，每组连接线生长 400ms，端点在对应连接线长成后用 200ms 淡入，标题同时用 400ms 淡入；标题淡入结束后描述再用 400ms 淡入。密集视口将相邻节点分组，同组一起生长；可见详情过多时先统一淡入标题，再淡入描述。可见描述超过64条或可见连接线分段超过128段时直接显示静态终态，以限制动画数量。连接线预先按文字边界分段，生长过程不使用事件 SVG 遮罩或动态裁切。相同时间线已展示时重复打开不重播；重渲染、刷新或页面返回不重播。拖动、滚轮、键盘或焦点操作、画布尺寸变化、画布停用以及减少动效立即结束生长，主线和节点恢复完整；不阻塞交互，不重建画布或编辑会话。

浮层与其遮罩作为一个交互同步开始变化；菜单项、表单字段、文件列表和文字不逐项淡入。组件嵌套时不叠加父子入场效果。重新渲染、窗口重新聚焦、数据刷新或页面返回不重播历史入场。

时间线端点的呼吸圆环不属于本风格，目标为静态标记；端点聚焦依靠清晰焦点指示，不改变圆环大小。不得为了“拖拽把手效果”显示并不存在的拖拽能力。真实可拖动对象可以在悬停时即时显示其已存在的操作手柄；只读或不可拖动条目不显示虚构手柄。

### M-03｜操作先于表现

用户操作立即触发真实状态变化或业务流程。150ms 是淡入淡出的完成时长，不是等待时间；过渡不能成为提交、选值、保存、关闭或导航的前置条件，也不能延迟成功／失败结果。是否允许关闭、切页或编辑仍由所属业务流程决定。

## 03. 统一参数

### 时间与属性

| 时长 | 用途 | 示例 |
| --- | --- | --- |
| 0ms | 即时状态与结构变化 | 输入、拖动、焦点、按下、禁用、选值、页面／正文切换、主题／密度切换、布局重排 |
| 150ms | 普通状态颜色与浮层透明度过渡 | 同主题下经过对比度验证的表面反馈；菜单、Popover、Tooltip、Dialog 内容淡入淡出 |
| 400ms | 打开时间线时主线生长 | 单条主线从左向右展开；交互或减少动效时立即结束 |
| 700ms | 时间线刻度生长 | 主轴完成后从左向右、由下往上生长 |
| 500ms | 时间线数字标签显现 | 刻度完成后从左向右、由下往上显现 |
| 1600ms | 时间线节点生长 | 主线完成后从左到右生长，交互或减少动效时立即结束 |
| 500ms | 时间线事件文字悬停缩放；Tooltip 意图判断延迟（不属于动画） | 时间线主标题1至1.2倍、副文字1至1.05倍并平滑恢复；自绘 Tooltip 显示前的等待，二者用途不同 |

普通状态颜色和浮层透明度过渡固定为 150ms，使用共享变量。时间线事件文字缩放例外使用时间线插件私有的 500ms 时长；时间线主线和节点生长分别使用插件私有的 400ms 和 1600ms 时长；各主题、密度和视口使用相同节奏。Tooltip 的 500ms 意图延迟独立于此动画时长。颜色变化时文字与背景必须成套；主题切换始终同步替换完整配色，不做混色过渡。

### 曲线与位移

| 参数 | 目标 | 规则 |
| --- | --- | --- |
| 进入／状态曲线 | `cubic-bezier(.2, 0, 0, 1)` | 用于允许的颜色、透明度与时间线事件文字悬停缩放 |
| 时间线连接线生长曲线 | `cubic-bezier(0, .55, .45, 1)` | easeOutCirc：开始较快，逐渐减速 |
| 退出曲线 | `cubic-bezier(.4, 0, 1, 1)` | 仅供允许的颜色或透明度过渡使用 |
| 位移 | `0px` | 不使用位移过渡；浮层用最终位置显隐 |
| 缩放 | 仅时间线事件文字、主标题短横线与打开时的主线；标题 `1 ↔ 1.2`，日期／时间偏移和摘要 `1 ↔ 1.05`，短横线 `scaleX(1 ↔ 1.2)` | 背景透明，短横线线宽维持1px；主线只在打开时水平生长且线宽不变；不缩放其他控件、端点、其他线条、焦点指示或装饰标记 |
| 透明度 | `0 ↔ 1` | 整个浮层同步变化，不单独延迟文字 |

```css
:root {
  --ui-duration-fast: 150ms;
  --ui-duration-normal: 150ms;
  --ui-duration-dialog: 150ms;
  --ui-ease-enter: cubic-bezier(.2, 0, 0, 1);
  --ui-ease-exit: cubic-bezier(.4, 0, 1, 1);
  --ui-motion-offset: 0px;
  --ui-tooltip-delay: 500ms;
}
```

通用时长沿用 [tokens.css](../src/styles/tokens.css) 中的变量名，不另建重复时长表。组件可建立语义别名，但不得复制数值。时间线文字缩放的局部例外由插件在 `.timeline-events-overlay` 定义 `--timeline-event-text-duration: 500ms`，系统或用户减少动效时归零；它不覆盖通用时长或新增主题颜色字段。主线和节点时长由 `.timeline-axis-line` 的 `--timeline-axis-growth-duration: 400ms`、`--timeline-axis-tick-stage-duration: 700ms`、`--timeline-axis-label-stage-duration: 500ms`、`--timeline-axis-mark-duration: 250ms`、`--timeline-branch-growth-duration: 1600ms`、`--timeline-branch-reveal-duration: 400ms` 、`--timeline-event-appear-duration: 200ms` 与 `--timeline-text-appear-duration: 400ms` 定义，JS 读取这些值；减少动效时取消动画。JS 如确需计时，应读取有效配置，不得维护另一组硬编码毫秒数。

## 04. 场景规范

| 场景 | 进入／变化 | 退出／恢复 | 约束 |
| --- | --- | --- | --- |
| Button、IconButton、列表行、工具栏按钮 | 允许的悬停颜色 150ms；按下、选中、禁用与焦点即时 | 悬停颜色 150ms；按下即时结束 | 不移动、不缩放、不改变边框或阴影，不改变尺寸、文字起点或命中区 |
| 输入框、搜索框 | 焦点、输入、校验即时；错误说明就地出现 | 即时 | 不渐显焦点、不抖动、不清空输入 |
| Select、动作菜单、Popover | 浮层整体淡入 150ms | 整体淡出 150ms | 定位固定在最终位置；选值与键盘高亮即时；菜单项不逐项过渡 |
| 右键菜单 | 整体淡入 150ms | 普通收起淡出 150ms；切换区域、执行动作或停用时即时关闭 | 同一时刻只保留一个有效菜单；新菜单不等待旧菜单淡出 |
| Tooltip（自绘实现） | 意图等待 500ms，再淡入 150ms | 淡出 150ms；Esc 或触发器消失时即时收起 | 不位移；原生 `title` 行为由平台决定 |
| Dialog | 内容与遮罩同时淡入 150ms；每次打开时居中 | 内容与遮罩同时淡出 150ms | 开合期间不位移、不缩放；标题栏直接拖动即时跟随，不做位置过渡；内容尺寸变化只修正越界，不重新居中；拖动时 Escape 撤销本次移动但不关闭弹框；焦点、关闭保护和业务状态仍归共享弹框与业务插件管理 |
| 浮动导航、辅助面板 | 仅新显内容淡入 150ms；结构与最终位置即时到位 | 淡出 150ms；关闭业务状态即时更新 | 不推挤正文，不从屏幕外滑入 |
| 停靠面板开合 | 栅格、宽度和布局立即到位；新显内容可淡入 150ms | 立即收回占位；残留仅可作为无交互淡出 | 正文尺寸不插值；拖宽、窗口变化与恢复即时 |
| 工程树展开／折叠 | 子节点与箭头方向即时更新 | 即时 | 不做高度动画、箭头旋转或深层级联动画 |
| 时间线主线与节点 | 主线从左向右生长400ms，刻度从左向右、由下往上生长700ms，数字标签随后显现500ms，接着连接线从左向右逐步从主轴向上或向下生长1600ms，端点用200ms淡入、标题同时用400ms淡入，随后描述用400ms淡入 | 交互、画布尺寸变化、停用或减少动效时即时显示完整主线和节点 | 刻度及数字标签最多各分为24组；不重播刷新或普通重渲染；节点最多分为24组；详情动画最多128项，超出时标题统一淡入；描述最多64条、连接线最多128段，超出时显示静态终态 |
| 时间线事件文字组 | 支持悬停时500ms同时缩放：主标题至1.2倍、日期／时间偏移和摘要至1.05倍、标题短横线以scaleX伸至1.2倍且线宽1px | 移出500ms平滑恢复；减少动效或画布停用时即时恢复 | 同曲线、同时开始；无背景高亮，左右锚点固定；节点、其他线条、布局与点击区域不变 |
| 文稿标签、正文、导航 | 选中标记、内容、位置与导航即时更新 | 即时 | 不横滑、交叉淡化或追踪下划线；保留页面实例与业务约定的状态 |
| 加载、保存、成功、失败 | 原位呈现真实状态文字和必要图标 | 按真实状态即时更新 | 不扫光、勾选描边、闪光、字数滚动或编造进度；失败信息保留至处理或解除 |
| 主题、密度及布局实现切换 | 同一更新批次应用全部目标值 | 即时 | 不全屏淡化、颜色渐变、位移或重挂载正文 |

### M-04｜颜色变化保持可读

颜色过渡只用于同一主题内、按 UI 设计规范验证过的交互状态。实施时检查过渡过程的 0%、25%、50%、75% 与 100% 状态；所有文字对比度符合规范、必要边界与指示可辨，才能使用 150ms 过渡。自定义主题无法保证时直接替换颜色。

主题切换必须同步替换前景、背景、边界、阴影颜色、焦点环、选区、滚动条与 Portal 内容，不经过中间混色。全局减少动效规则不能覆盖作者正文或第三方编辑器的全部样式。

### M-05｜加载与保存

请求开始时呈现真实处理状态。可以稳定保留内容区域，不先清空再制造占位；不编造百分比或最短等待。`pending`、`saving`、`saved`、`error` 由项目存储拥有，文档能力向界面转发。写作状态插件只呈现状态，不另建保存计时器。失败和重试入口保留用户内容。

## 05. 打断、关闭与资源清理

### M-06｜连续操作

再次开合时以最新状态为准，不排队播放多次动画。菜单高亮、选值和编辑器选区不等待淡入。偏好、窗口或父状态变化时，界面立即收敛到正确终态。

一个关闭中的菜单被另一菜单替换时，立即停止旧视觉状态并取消其回调，再展示新菜单。旧动画回调不得关闭后来重新打开的浮层。

### M-07｜语义关闭与视觉退出

短暂的透明度退出不能延长业务流程。共享弹层继续沿用 Base UI 的挂载、焦点与关闭模型，不另写页面级延迟卸载。

- 非模态浮层关闭后停止命中和键盘交互；焦点移到合理目标，不能留在隐藏或 `inert` 子树中。
- 模态淡出期间继续保持焦点限制与遮罩语义，避免点击穿透；退出结束或跳过后恢复焦点。触发器已消失时，使用业务指定的 `finalFocus` 或稳定的邻近操作。
- 父级卸载、导航提交或插件停用时即时移除浮层，不保留读取已释放服务的内容。
- 0ms、无过渡属性、动画取消或节点提前移除时，清理仍须完成。不能只依赖 `transitionend`／`animationend`；提供取消路径和有限兜底，兜底不得延迟业务动作。

普通收起先更新受控 `open`，再由共享组件管理视觉退出。关闭权限仍由原业务状态决定，例如保存失败时留在原页面。

### M-08｜状态和实例保留

布局隐藏继续遵守 `LayoutService.hide` 的“保留组件实例”契约；隐藏内容的 `active` 立即变为 `false`。淡出残留只能是无交互呈现，不能继续响应快捷键或访问已停止业务。

不通过更换 React `key`、重建编辑器或重启会话实现过渡。组件撤销自己创建的计时器、动画对象、帧回调、媒体查询和 DOM 监听；隐藏页面停止非必要动效，返回时不补播已错过的动画。

## 06. 减少动效

### M-09｜规则与优先级

用户偏好提供“跟随系统（默认）／减少动效”。系统要求减少，或用户选择减少，任一成立即启用减少模式；不提供覆盖系统偏好的强制完整动效。系统偏好通过 `prefers-reduced-motion` 读取。[MDN 说明](https://developer.mozilla.org/en-US/docs/Web/CSS/@media/prefers-reduced-motion)

减少模式将本规范允许的插值时长设为 0ms，并取消时间线事件文字悬停缩放，维持原尺寸，时间线主线和节点直接显示完整状态；TXT 自绘光标停止闪烁并保持可见。本规范禁止的位移与其他缩放仍不启用。浮层开合、灰蓝焦点、选中背景、加载与错误信息仍即时呈现最终状态。Tooltip 意图判断延迟保留；业务请求和保存调度不受影响。原生光标和用户主动滚动不被禁用。

```css
:root[data-ui-motion="reduce"] {
  --ui-duration-fast: 0ms;
  --ui-duration-normal: 0ms;
  --ui-duration-dialog: 0ms;
  --ui-motion-offset: 0px;
}

@media (prefers-reduced-motion: reduce) {
  :root {
    --ui-duration-fast: 0ms;
    --ui-duration-normal: 0ms;
    --ui-duration-dialog: 0ms;
    --ui-motion-offset: 0px;
  }
}
```

不得用 `* { animation-duration: .01ms !important }` 代替设计；不覆盖编辑器正文、作者内容与原生交互。第三方编辑器的界面动效由其格式插件适配减少模式。

### M-10｜偏好实现归属

现有目标实现中，UI 插件拥有应用级呈现偏好。`@lodestory/sdk/ui` 的 `uiMotionConfig` 配置声明 ID 为 `ui.motion`，值为 `system | reduce`，默认 `system`，使用 `effect: "live"` 实时生效；这是配置声明，不是新的动效服务。

UI 插件登记该项并订阅配置，向 `document.documentElement` 设置或移除 `data-ui-motion="reduce"`。设置插件依赖配置项拥有者提供的 `uiKey` 与 `configKey`，读取和写入使用同一配置声明。CSS 媒体查询始终保留系统兜底。主题与布局插件不持有该偏好，切换主题不改变动效设置。

根元素属性覆盖 Portal 中的菜单和弹框。应用停止时先停止 UI，再取消订阅、撤销配置登记并恢复接管前的属性；部分初始化失败也执行清理，不能在 `main.tsx` 追加业务初始化。配置写入失败沿用 `ConfigService` 规则：保留原有效值并反馈失败，不虚报已保存。

WCAG 2.3.3（AAA）涉及可关闭非必要的交互运动；本规范提供减少动效策略，但不据此宣称整个应用已符合 WCAG。[W3C 说明](https://www.w3.org/WAI/WCAG22/Understanding/animation-from-interactions.html)

## 07. 实现与性能约束

- 使用显式过渡属性；禁止 `transition: all`。只允许过渡颜色、透明度、时间线事件文字及打开时主线的 `transform`，以及刻度、数字标签的裁切区域；连接线使用预分段与描边生长，不使用事件 SVG 遮罩或动态裁切。
- 不动画化位移、宽高、栅格列宽、字号、行高、边框颜色或阴影；`transform` 仅用于 M-02 的事件文字缩放与主线生长，浮层仅改变透明度。
- 阴影、模糊与背景滤镜保持静态；不通过整页截图、复制编辑器 DOM 或全屏过渡模拟连续性。
- 不永久设置 `will-change`；逐帧代码不触发 React 业务状态更新，不反复交替读取与写入布局。
- 若后续某个浮层在透明度过渡时出现性能问题，先移除过渡、保证即时显隐；60Hz 的约 16.7ms 帧预算属于验收观察目标，不作为继续引入运动属性的理由。

| --- | --- |
| 检查 CSS 与共享变量 | 一般状态颜色和浮层透明度150ms；时间线事件文字缩放500ms、主线生长400ms、刻度生长700ms、数字标签显现500ms、节点生长1600ms；无位移或其他缩放，无悬停边框／阴影变化 |
