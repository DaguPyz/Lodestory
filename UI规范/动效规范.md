# Lodestory · 统一动效规范

**版本：1.0 ｜ 日期：2026-10-22 ｜ 状态：现有页面与共享组件已接入；跨平台原生客户端及性能验收待完成**

本规范细化 [UI 设计规范](UI设计规范.md)的 MOT-01，沿用“简约、清新、安静、精细”的方向与 100／160／220ms 基线。适用于全部自绘界面、公共组件与插件贡献；原生窗口、系统对话框和系统光标遵循平台行为。

**核心要求：操作立刻生效，辅助界面短促过渡，正文始终稳定。** 时长和位移是 Lodestory 的产品设计值，不是外部标准规定的数值。下文“应／不得”为实施要求，“现状”为本次源码核对结果。

## 01. 归属与接入

| 项目 | 约定 |
| --- | --- |
| 归属 | 共用时间、曲线和位移由应用的共享视觉变量统一定义；控件过渡归 `@lodestory/ui`；布局、右键菜单、工程树、文档标签和写作状态归各自插件。数据和业务流程仍由原插件拥有，无需建立独立动效插件。 |
| 协作 | 复用 `uiKey`、`layoutKey`、文档及工作台公开能力。纯样式不新增服务 key；公共组件不读取其他插件的私有状态。若实施用户偏好，只新增共享配置项，见第 06 节。 |
| 接入 | 页面及根包装仍由 UI 服务登记，工作台内容仍通过布局服务按用途登记；控件经 `@lodestory/ui` 使用。默认插件继续由 `appPlugins.ts` 显式装配，入口不编排动画。 |
| 生命周期 | 偏好与监听属于应用实例；布局呈现属于工作台；控件动画属于组件。动效不能接管文档保存、离开检查和资源释放，停用时先停止 UI 使用资源，再释放资源。 |
| 验收 | 替换布局或主题无需修改业务消费者；隐藏与重开不重建编辑会话；减少动效、连续操作、保存失败与停用场景均保留正确状态和用户内容。 |

`src/plugin-core/` 不增加动效、页面或编辑器知识。SDK 只容纳必要的共享契约，不放 CSS、动画实例或组件实现。

## 02. 动效语言

### M-01｜让用户理解变化

动效只用于确认操作、说明浮层出现的位置、帮助辨认辅助区域显隐。写作工作台没有品牌开场动画、页面编排或持续吸引注意的元素。

每次变化优先只动一个容器；对话框与其遮罩视为一个交互。菜单项、表单字段、文件列表不逐项延迟出现。组件嵌套时不叠加父子入场动画。

### M-02｜内容稳定

- 正文输入、中文输入法合成、光标、选区、撤销重做、滚动和拖动即时响应，不人为增加等待或缓动。
- 文档切换、标签选择、主题切换、搜索结果更新和保存状态变更不做装饰动画。
- 不使用弹簧回弹、按钮缩放、悬停上浮、错误抖动、翻页、视差、扫光或自动循环。
- 隐藏后再次显示可以执行所属容器的一次过渡；后台数据刷新、重渲染和窗口重新聚焦不重播入场。

### M-03｜行为先于表现

点击后立即更新适用的语义状态或开始真实业务操作。100ms 是反馈完成的时长，不是等待 100ms 再响应。动画不能成为提交、选值、保存或导航的前置条件，也不能为了“播完”延后成功／失败结果。

是否允许关闭、切页或编辑由业务状态决定；不得仅因动画正在播放而设置 `busy` 或禁用操作。

## 03. 统一参数

### 时间

| 时长 | 用途 | 典型实例 |
| --- | --- | --- |
| 0ms | 直接操作、关键状态、结构重排 | 输入、拖动、焦点、禁用、选值、正文切换、主题切换 |
| 100ms | 小范围反馈；轻浮层退出 | 同主题悬停反馈、菜单退出、Tooltip 显隐 |
| 160ms | 常规辅助区域进入；对话框退出 | 菜单／Select／浮动面板进入、对话框退出 |
| 220ms | 低频对话框进入 | 新建项目、新建文档、删除确认 |

一次普通交互的视觉变化在 220ms 内结束；遮罩和内容同时开始，不串行播放。业务耗时、Tooltip 的触发延迟不计入动画时长。各主题、密度和窗口尺寸使用相同节奏。

### 曲线与位移

“曲线”描述变化如何加速、减速：进入快速启动、柔和停稳；退出迅速离开。

| 参数 | 值 | 用法 |
| --- | --- | --- |
| 进入／状态过渡 | `cubic-bezier(.2, 0, 0, 1)` | 菜单、弹框进入；经验证的颜色反馈 |
| 退出 | `cubic-bezier(.4, 0, 1, 1)` | 菜单、弹框退出 |
| 位移 | 默认 0，浮层最多 4 CSS px | 不随浮层尺寸、密度或文稿字号放大 |
| 透明度 | 0 ↔ 1 | 整个浮层同步变化；不单独延迟文字 |
| 缩放 | 恒为 1 | 避免文字缩放和模糊 |

锚定浮层从靠近触发器的方向移动到最终位置：位于触发器下方时起点 `translateY(-4px)`，上方为 `translateY(4px)`，右侧为 `translateX(-4px)`，左侧反向。边缘避让后的实际位置决定方向；无法可靠取得方向时只淡入。退出回到同一起点。右键菜单只淡入，避免给没有固定触发按钮的菜单附加方向。

居中对话框从最终位置下方 4px 进入，退出下移 4px。不得覆盖其居中定位所用的 `translate(-50%, -50%)`；定位与动效应分层或正确组合。

### 共享变量

```css
:root {
  --ui-duration-fast: 100ms;       /* 已有：短反馈／轻浮层退出 */
  --ui-duration-normal: 160ms;     /* 已有：轻浮层进入／对话框退出 */
  --ui-duration-dialog: 220ms;     /* 对话框进入 */
  --ui-ease-enter: cubic-bezier(.2, 0, 0, 1);
  --ui-ease-exit: cubic-bezier(.4, 0, 1, 1);
  --ui-motion-offset: 4px;         /* 最大浮层位移 */
  --ui-tooltip-delay: 500ms;       /* 触发延迟，不是动画时长 */
}
```

沿用当前变量命名，不另建相同意义的时长表。公共基础值现阶段放在 [tokens.css](../src/styles/tokens.css)；组件可以建立内部语义别名，但不能复制数值。JS 确需计时时读取有效值，不维护另一套硬编码毫秒数。

## 04. 场景规范

| 场景 | 进入／变化 | 退出／恢复 | 关键约束 |
| --- | --- | --- | --- |
| Button、IconButton、列表行、工具栏按钮 | Hover 可用 100ms；Pressed、Selected、Disabled 和焦点标记立即呈现 | Hover 恢复 100ms；松开立即结束按下态 | 不移动、缩放，不改变宽度、文字起点和命中区；颜色规则见下文 |
| 输入框、搜索框 | 焦点环、输入、校验结果即时；错误文字就地出现 | 即时 | 焦点不渐显；不抖动、不自动清空输入 |
| Select、动作菜单、Popover | 160ms，透明度＋最多 4px 锚点位移 | 100ms，反向变化 | 选值或执行动作即时；键盘高亮即时；菜单项不逐项动画 |
| 右键菜单 | 160ms，只淡入 | 普通收起 100ms；切换右键区域时立即移除旧菜单 | 任意时刻只保留一个有效菜单，不能为退出动画延迟新菜单 |
| Tooltip（自绘实现） | 等待 500ms 后，以 100ms 淡入 | 100ms 淡出；Esc、触发器消失时立即收起 | 不位移；延迟不是点击反馈；原生 `title` 行为由平台决定 |
| Dialog | 内容 220ms，透明度＋下方 4px；遮罩 160ms，只改透明度 | 内容 160ms；遮罩 100ms；同时开始 | 新建与删除确认采用同一节奏；聚焦／关闭保护归共享弹框及业务插件 |
| 浮动导航／辅助面板 | 160ms，透明度＋朝停靠边最多 4px 位移 | 100ms，反向变化 | 不从屏幕外长距离滑入，不推挤正文 |
| 停靠面板开合 | 栅格与宽度立即到位；展开时仅新显内容淡入 160ms | 立即隐藏并收回占位 | 不插值正文区域宽度，避免正文连续重排；窗口变窄、恢复及拖动不淡入 |
| 工程树展开／折叠 | 子节点立即出现／隐藏；箭头可旋转 90°，100ms | 反向 100ms | 结构不做高度动画；深层树不级联播放；无箭头的设计不专为动画加箭头 |
| 文稿标签与正文 | 选中标记、内容切换、关闭与位置补齐即时 | 即时 | 不做横滑、交叉淡化或下划线追踪；保存与关闭规则照常执行 |
| 欢迎页、工作台、设置页导航 | 导航获准后直接显示目标页 | 直接隐藏旧页 | 不叠放两个活动页面；保留已访问页面实例与业务约定的状态 |
| 加载、保存、成功、失败 | 原位更新静态文字与必要图标 | 依据真实状态更新 | 不做字数滚动、勾选描边、成功闪光；失败信息保留到处理或状态解除 |
| 主题、密度及布局实现切换 | 同一更新批次中应用目标值 | 即时 | 不全屏淡化、不圆形扩散、不播放颜色渐变；不重挂载正文 |

### M-04｜颜色反馈不牺牲可读性

文字与表面始终采用主题约定的成套颜色。100ms 颜色过渡只适用于同一主题下、全过程对比度符合 UI 规范的状态；实施时验证中间状态，至少检查进度 0／25／50／75／100%。任一状态不满足或自定义主题无法保证时，同步直接替换颜色，禁止通过任意混色“补效果”。

主题切换必须绕过颜色过渡，前景、背景与边界同步替换。全局取消过渡只作用于界面状态颜色，不能粗暴取消作者内容或第三方编辑器的全部样式。**即时颜色反馈是合格的降级，不强制每个控件都运动。**

### M-05｜加载与保存

请求开始即提供真实处理状态；可保持内容区域稳定，不先清空再制造占位。当前版本采用静态占位和“正在打开／正在保存”等文字，不引入持续转圈或骨架扫光，不编造百分比，不规定虚假的最短等待时间。

`pending`、`saving`、`saved`、`error` 以文档服务的状态为准。写作状态插件只呈现，不重建保存计时器；自动保存当前的 700ms 调度不属于动效参数。错误与重试入口保留用户内容，不能为了完成过渡收起失败视图。

## 05. 打断、关闭与资源清理

### M-06｜连续操作

再次开合时以最新目标为准，从当前视觉值继续；不能把多次点击排成动画队列。菜单高亮、选值和编辑器选区恢复不等待淡入结束。动画中调整窗口或改变减少动效偏好时，直接收敛至正确终态。

若一个关闭中的菜单被另一菜单替换，立即结束旧视觉状态、取消其回调，再展示新菜单。旧动画完成回调不得关闭后来重新打开的浮层。

### M-07｜语义关闭与视觉退出

“视觉退出”只让外壳短暂淡出，不延长业务流程。共享弹层应沿用 Base UI 的挂载、焦点与关闭模型，不能另写页面级延时卸载逻辑。

- 非模态浮层关闭后停止命中和键盘交互；焦点移到合理目标，不落在隐藏或 `inert` 的子树中。
- 模态退出期间保持正确的焦点限制和遮罩语义，防止点击穿透；视觉退出完成或被跳过后恢复焦点。触发器已消失时，使用业务指定的 `finalFocus` 或稳定的邻近操作。
- 若业务父级已卸载、导航已提交、插件正在停用，直接跳过退出动画，不保留还会读取已释放服务的旧内容。
- 0ms、没有过渡属性、动画取消或节点提前移除时，也必须完成收尾。不能只等 `transitionend`／`animationend`；需要取消路径与有限兜底，且兜底不用于延迟业务动作。

普通收起应先更新受控 `open`，由共享组件管理视觉退出；父级因导航等原因直接卸载时，允许即时消失。是否关闭仍由原插件决定，例如忙碌时的关闭保护、保存失败时留在原页面。

### M-08｜状态和实例保留

布局隐藏继续遵守 `LayoutService.hide` 的“保留组件实例”契约；隐藏内容的 `active` 立即变为 `false`。淡出残留如存在，只能是无交互的呈现，不能继续运行快捷键或调用已停止的业务。

进入动画不通过更换 React `key`、重新创建编辑器或重启会话实现。取消并释放本组件创建的动画对象、计时器、帧回调、媒体查询及 DOM 监听；隐藏页面停止非必要动效，返回时不补播历史动画。

## 06. 减少动效

### M-09｜规则与优先级

目标提供两个用户选项：**跟随系统（默认）／减少动效**。系统要求减少，或用户选择减少，任一成立即采用减少模式；不提供覆盖系统偏好的“强制完整动效”。系统偏好通过 `prefers-reduced-motion` 读取。[MDN 说明](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/prefers-reduced-motion)

减少模式中，本规范所有插值时长为 0ms，浮层位移与树箭头的旋转过程取消；开合、箭头方向、焦点环、选中、加载及错误提示仍立即呈现最终状态。Tooltip 的 500ms 意图判断延迟保留；业务请求和保存调度不受影响。原生光标和用户主动滚动不被禁用。

```css
/* 目标：覆盖界面动效变量；组件仍须保证 0ms 的完整生命周期。 */
:root[data-ui-motion="reduce"] {
  --ui-duration-fast: 0ms;
  --ui-duration-normal: 0ms;
  --ui-duration-dialog: 0ms;
  --ui-motion-offset: 0px;
}

@media (prefers-reduced-motion: reduce) {
  :root {
    --ui-duration-fast: 0ms;
    --ui-duration-normal: 0ms;
    --ui-duration-dialog: 0ms;
    --ui-motion-offset: 0px;
  }
}
```

不得用 `* { animation-duration: .01ms !important }` 代替设计；不覆盖编辑器正文、作者内容与原生交互。第三方编辑器的界面动效由其格式插件适配减少模式。

### M-10｜偏好实现归属

UI 插件拥有这一应用级呈现偏好。`@lodestory/sdk/ui` 提供共享 `uiMotionConfig` 配置声明，ID 为 `ui.motion`，值为 `system | reduce`，默认 `system`，使用 `effect: "live"` 实时生效，校验函数只接受这两个字符串；它是配置声明，不是新的动效服务。

UI 插件登记该项、订阅配置，向 `document.documentElement` 设置或移除 `data-ui-motion="reduce"`；设置插件保留对配置项拥有者所提供的 `uiKey` 的依赖，并新增 `configKey` 依赖，使用同一个配置声明读取及写入。CSS 媒体查询始终保留系统兜底。主题插件、主题包和布局插件不各自持有偏好，切换主题不改变动效设置。

根元素覆盖必须包含 Portal 中的菜单和弹框。应用实例停止时，先停止 UI，再取消订阅、撤销配置登记并恢复自己接管前的属性；部分初始化失败同样清理，不能在 `main.tsx` 追加业务初始化。配置写入失败沿用现有 `ConfigService` 规则：保留原有效值并反馈失败，不虚报已保存。

WCAG 2.3.3（AAA）要求可关闭非必要的交互运动；本规范采用上述统一减少策略，但不据此宣称整个应用已符合 WCAG。[W3C 说明](https://www.w3.org/WAI/WCAG22/Understanding/animation-from-interactions.html)

## 07. 实现与性能约束

- 优先使用 CSS 的显式属性过渡；不使用 `transition: all`。动态打断确需脚本时再使用浏览器动画能力，本版不要求新增动画库。
- 浮层以 `opacity`、`transform` 为主；禁止对正文相关容器的 `width`、`height`、栅格列宽、字号和行高逐帧插值。工程树也不做高度动画。
- 阴影、模糊和背景滤镜保持静态；不通过整页截图、复制编辑器 DOM 或全屏过渡模拟连续性。
- 不永久设置 `will-change`；逐帧代码不触发 React 业务状态更新，不反复交替读取与写入布局。
- 以目标设备的 60Hz 显示为基准检查约 16.7ms 的帧预算；这是验收目标，不是当前性能结论。转换属性不等于自动获得流畅表现，必须记录实际帧情况。

现有 `@lodestory/ui` 文档明确颜色直接替换，这一现状不能被误写为已具备 100ms 动画。表中 Tooltip 等规则约束后续自绘实现，不代表当前已有相应共享组件。完整应用的在线插件热装卸也不在本次规范的能力承诺内。

## 09. 验收清单

| 验收动作 | 通过条件 |
| --- | --- |
| 检查参数与插件引用 | 同类场景使用同一变量；无插件私有导入、新全局单例或内核业务分支 |
| 打开／关闭菜单与弹框 | 时长和位移符合第 04 节；遮罩与内容同时开始；位置不跳变，无双菜单残留 |
| 100ms 内连续开合、快速切换菜单区域 | 以最新操作为准，无排队、旧回调误关闭、残余遮罩或透明命中区 |
| Tab、方向键、Enter、Esc 操作 | 焦点即时可见；菜单高亮即时；模态焦点限制和关闭恢复正确；输入法合成不被打断 |
| 普通／减少模式逐一开合；动画中切换偏好 | 0ms 也完成显隐与清理；状态信息不丢失；系统减少优先，Portal 同样生效 |
| 编辑正文时开合面板、拖宽、换标签、换主题 | 无连续正文重排、选区丢失、输入焦点跳动、编辑器重建或文稿内容改写 |
| 提交／保存失败后关闭或切页 | 遵守原关闭与离开检查，失败保留内容；动画完成不被当作业务完成 |
| 浮层打开时切页、父级卸载或停止应用 | 立即结束视觉残留；组件先停止使用服务，再释放服务，无悬挂计时器 |
| 替换主题与布局实现 | 业务插件无需改代码；颜色全过程可读，无法保证时直接替换；新布局遵守相同状态和动效规则 |
| 录制操作过程和性能轨迹 | 每次只出现必要过渡，无长期循环、逐帧布局抖动或明显掉帧；关键动画需看完整过程，静态截图不能证明流畅 |
