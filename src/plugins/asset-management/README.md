# 资产管理插件

资产管理插件拥有项目内的类型模板、资产记录与属性值，并通过 `projectStorageKey` 使用项目存储提供的字节缓冲。字段 ID 是稳定关联标识，字段标题只用于展示。

schema 存放在 `.lodestory/assets/schema.json`，文件格式标识为 `lodestory.asset-schema`，当前版本为 `schemaVersion: 2`，根对象包含 `types`、`assets` 和 `fields` 三个数组。插件可以读取版本 1 的类型模板文件；首次成功写入时再升级到版本 2。资产记录包含 ID、名称、说明、类型 ID 和属性值；属性值以字段 ID 为键保存。字段定义包含独立 ID、所属类型或单个资产、标题、值类型、配置、顺序、状态及可选默认值。

字段值类型为 `text`、`number`、`singleSelect`、`multiSelect` 和 `reference`。单选与多选配置各自带有稳定 ID 的选项；关联字段可指定目标类型 ID。值会按字段类型和选项校验，关联值必须指向目标类型的现有资产。导航先列出启用的资产模板及对象数；选择模板会选中对应类型、清除对象选择，并打开按该模板筛选的对象列表。对象列表支持列表和卡片两种查看模式，默认列表；右上方的图标按钮提供悬停提示和无障碍名称，当前模式由 `aria-pressed` 标记。切换模板或从对象详情返回时，在当前项目会话内保留所选模式，重新打开项目时重置为列表；该模式不写入项目 schema。列表视图将对象简介放在名称列中；卡片按名称和简介、模板字段与值、底部操作区分层展示。新建对象时沿用当前模板，按其字段展示并初始化默认值；不再通过对象表单单独选择类型。模板字段只适用于类型匹配的对象。用户也可以给单个对象添加独立字段，这些字段只属于该对象。创建后当前版本不支持更改对象类型；之后新增的模板字段不会回填到既有对象。字段顺序以所属类型或对象内的整数 `order` 保存；重命名只改 `title`，保留字段 ID。

## 导航与对象列表呈现

资产模板导航每项以单行显示模板名称和对象数；字段数集中显示在右侧视图标题中。“未分类对象”行同样显示对象数。对象列表不绘制逐行外框，列宽随内容自然展开，首列固定，其他列在列表区域内横向滚动。点击对象名称打开详情，不再另设重复的查看按钮。删除图标在鼠标悬停或行内获得键盘焦点时出现，触屏设备始终显示。模板字段完整显示；字段名为“名称”时也不会因此隐藏对应数据。这些属于呈现和交互调整，不改变数据模型或项目会话生命周期。

“未分类对象”导航范围保留旧数据中未分类或类型已归档的对象；当前界面不允许新建未分类对象。

删除资产前会要求确认。删除会一并移除该资产的专属字段及属性值，类型模板和其他资产保持不变；如果其他资产仍通过关联字段指向它，必须先解除这些关联，资产自身指向自己的引用不会阻止删除。删除单个专属字段也需要确认，只会移除该字段定义和所属资产中的对应值。保存失败时保留待删除状态，并可重试；离开项目会先尝试保存，失败则保留当前项目会话。

删除类型模板也需要确认，并会一并移除该类型的模板字段，但不会删除资产或其他类型。只要仍有资产使用该类型，或该类型之外的关联字段将它设为目标，就会阻止删除；该类型自己的模板字段即使指回本类型，也会随模板一起删除，不构成阻止条件。当前版本尚无修改或删除类型模板字段配置、解除外部引用的界面，因此被资产使用或被外部引用的类型暂时无法删除。保存失败时保留待删除状态并支持重试。

插件通过 `layoutKey` 登记“资产管理”导航、“模板设置”主视图和“对象管理”主视图。导航入口保留 `asset-management.navigation` 与 `order: 20`；模板设置展示 `asset-management.types`，对象管理展示 `asset-management.assets`（`order: 21`）。侧栏空白处右键可新建资产模板；模板条目右键可打开模板设置。对象列表右键可新建对象或打开模板设置；没有选中模板时，右键对象列表可新建资产模板。模板设置主视图根区域右键可返回对象列表、编辑或删除当前模板，以及添加字段。打开对象详情后，详情根区域右键可返回对象列表、编辑或删除当前对象。新建模板的导航入口通过会话内请求打开模板表单；这是瞬时 UI 请求，不写入项目 schema。兼容布局可以自行决定各用途的呈现位置。

插件声明 `@lodestory/sdk/context-menu` 的 `contextMenuKey` 依赖，并将取得的 `ContextMenuService` 注入导航、模板设置和对象管理视图；菜单区域由共享 context-menu 插件提供。

每个工作台项目会话各自创建一个私有 schema store，资源不跨会话共享。会话开始时先登记资源，再加载数据；可恢复的读取失败保留在视图中，不阻止项目打开。未完成的表单会阻止离开项目；未保存的类型、字段或资产修改会在离开前重试保存，仍失败则保留会话与用户输入。停用时先撤回三项布局贡献，再撤销工作台参与并释放各会话 store。

类型模板、资产属性值及字段定义、标题修改和排序由资产管理插件负责；它不依赖时间线、文档或其他插件的私有实现，也不新增 SDK 能力。共享项目存储只提供按项目会话隔离的字节文件操作；编码、schema 校验和迁移都属于本插件。

验收应确认：导航 ID 和顺序保持稳定；两个主视图通过布局登记接入；按模板切换对象范围后，各类型对象值都保留，显式未分类范围不会被写操作重置；旧未分类对象可查看但不能新建；对象按当前模板带出字段，也能添加只属于该对象的字段；删除确认可取消，资产和类型删除都遵循各自的引用及使用约束，成功删除只清理目标记录和所属字段；同一项目的新会话可从共享项目存储恢复资产、字段和值；不同会话使用各自 store；未完成编辑和保存失败不会丢弃用户内容；停用插件会先停止视图，再释放会话资源。
