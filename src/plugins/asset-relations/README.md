# 资产关系插件

「编辑对象」中的资产关系面板支持添加、编辑和删除关系。填写关系描述，从项目的资产分类中选择关联对象，可给两端分别填写标签。分类下拉框支持按名称搜索，关联对象下拉框支持在当前分类内按名称或简介搜索。同一条关系可以从任一对象查询和维护。当前对象显示在左边，各自标签随对象换位，描述使用作者填写的原文。

关系插件拥有记录、校验、按资产查询的索引和对象编辑面板。通过 `assetEditorKey` 登记面板，通过 `assetCatalogKey` 取得项目内资产 ID、名称和分类。`assetRelationsKey` 提供按会话和资产 ID 查询的只读网络。应用静态装配此插件，激活需要上述资产管理能力、工作台及项目存储。撤回面板后释放会话资源，关系文件留在项目中。

每个项目在 `.lodestory/asset-relations/relations.json` 保存 UTF-8 JSON。第一次保存关系时创建。`schemaVersion` 用于识别文件结构，`relations` 内的每项按以下形状保存。

```json
{
  "format": "lodestory.asset-relations",
  "schemaVersion": 1,
  "relations": [
    {
      "assets": [
        { "assetsId": "20000000-0000-4000-8000-000000000001", "tag": "师父" },
        { "assetsId": "20000000-0000-4000-8000-000000000002", "tag": "徒弟" }
      ],
      "label": "萧炎拜药老为师"
    }
  ]
}
```

每条关系连接两个不同的资产 UUID。端点按 UUID 排序以便校验重复，记录读取与显示均可从任一端开始。`label` 修剪首尾空白后必填，`tag` 可省略。相同的两个对象可以有多条不同的关系，内容完全相同的关系只保存一次。资产分类用于筛选对象，名称和所属分类来自当前目录快照。

对象被删除后保留原关系，从另一端可查看并替换缺失对象或移除整条关系。文件读取失败时保留原文件并在面板内提供重试。保存使用项目存储提供的创建、写入、保存和冲突保护。保存失败时保留本次提交供重试，面板仍显示上一次成功保存的关系。未提交草稿和待重试写入参与编辑退出及项目离开检查。
