# 外部插件加载

桌面版在“设置 → 插件”选择 ZIP 后先导入，再立即尝试启用；已有的待加载包也可手动加载。启用状态单独保存在本机，应用下次启动后重新校验并恢复；实际加载失败会显示原因，不会显示为已启用。

加载插件调用插件包服务复查原始包摘要、清单、文件、平台与兼容版本，再按后端类型复用独立程序加载器 A 或动态库加载器 B。前端入口默认导出插件工厂；宿主将可选的 `options.backend` 传给工厂，其 `call` 接受 A、B 共用的请求和响应格式。后端的关闭由宿主管理。

目前对外开放 `lodestory/layout@0` 和 `lodestory/navigation-layout@0` 两种能力。插件代码的 `requires` 必须与交付清单一致，并使用宿主共享的 SDK key。工作台内容和导航页面在激活时暂存，成功保存启用状态后成组登记；加载期间不会重建已有 React 根节点。完整页面可从插件设置或应用导航打开，通过“返回上一页”回到原编辑界面；布局内容通过现有布局入口打开。全局根包装、导航守卫和初始化期间的独立导航操作不在此次开放范围内。

插件初始化失败时会尝试撤销贡献并关闭后端，保留已导入的包。若清理或记录回滚无法确认完成，界面显示原因并阻止重复启动；用户应先保存工作，再重新启动应用。回滚不会撤销插件代码自行写入的文件或远程操作。

在设置里停用插件时，宿主等待插件的保存准备，经过导航守卫离开其当前页面，再保存停用状态。宿主撤回该插件登记的页面、面板和导航操作，确认撤回后关闭后端。停用会保留安装包，允许重新启用。卸载会在确认停用后移除应用内的包文件和记录，保留项目内容及导入时选择的 ZIP。清理失败时设置页显示未完成状态，保留包供重试或恢复。

## 开发模式

在脚手架项目运行 `npm run dev`，然后在“设置 → 插件 → 插件开发模式”选择项目文件夹。每次成功构建都会发布带独立版本标记的文件。包服务校验后将完整产物复制到临时目录，加载器沿用相同的界面登记、后端调用和停用流程。若原插件页面或面板仍适合重新打开，加载器会在更新后返回该界面。

编译失败或旧版拒绝停止时，当前版本继续运行。新版加载失败时，宿主在确认资源已经释放后尝试恢复最近的可用版本。开发期间，同 ID 的已安装插件暂时让位，退出开发模式时恢复原先运行的安装版。开发模式随应用退出，终端中的构建监听可以用 Ctrl+C 停止。

插件依赖、外部插件对外提供共享能力、更新及市场尚未实现；无沙箱。桌面联调目前只覆盖 macOS arm64，Windows 和 Linux 尚未验证。
