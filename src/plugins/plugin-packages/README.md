# 插件包服务

插件包服务通过 `@lodestory/sdk/plugin-packages` 提供本地包导入、记录查询、安装文件移除和外部能力登记。管理界面通过设置分类接入。原生宿主负责选择文件、校验、解压与持久化。

首版宿主接口版本为 `0.1.0`。布局契约在 SDK 导出 `layoutExternalCapability`，当前实现提供布局能力时同时登记 `lodestory/layout@0` / `0.1.0`，停用时撤销；替换实现需要使用同一个布局契约并登记其实际支持的版本。导入只把已经登记的能力当作可验证依赖；其他插件的版本尚无运行目录，声明插件依赖的包会明确被拒绝，待加载的包不会冒充已激活的依赖。

宿主把源 ZIP、解压文件及包含摘要的记录放在应用数据目录的 `plugin-packages` 中。导入时逐个核对清单中所有产物的路径、大小和 SHA-256；不接受缺失或多出的文件。导入使用临时目录，检查成功后一次性移入正式目录；同一 ID（忽略大小写）不能覆盖。进程间文件锁保护提交与中断后清理。停止时等待正在进行的导入，失败不撤销已有包或文稿。

安装记录可在重启后查询。外部插件加载器负责激活、停止和释放运行资源。卸载时，包服务确认包已停用并释放资源，再将安装目录移到待清理区并删除。清理失败时保留重试所需的记录。移除范围限于应用数据目录里的安装副本。

开发模式读取脚手架发布的构建状态和版本标记，核对清单及文件后，将整版产物复制到宿主的临时目录。各版分别提供资源和后端路径，供加载器更新或恢复上一版。开发版和已安装版各自管理运行资源，安装记录只由普通安装操作更新。
