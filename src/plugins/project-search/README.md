# 项目搜索插件

项目搜索插件拥有项目会话内可重建的内存索引与搜索界面；不保存项目业务数据。工程管理、资产管理和时间线插件通过 `@lodestory/sdk/project-search` 分别登记来源，提供记录快照、变更订阅和打开操作。来源不暴露私有 store；工具栏通过公开事件请求打开搜索。

第一阶段搜索工程树中受支持文稿（`.md`、`.markdown`、`.txt`、`.lode`）的文件名及路径、资产名称／说明及可见字段值、时间线名称／说明和事件名称／说明，不搜索正文或工程树以外的文件。结果按类型分组，最多呈现 200 条并显示总数；标题和说明中的命中词使用主题搜索高亮色。打开事件结果进入所属时间线，暂不定位事件。名称及内容使用 NFKC 归一化和不区分大小写的子串匹配，中文可直接搜索。筛选、结果和错误均在当前会话内。

来源更新时索引按 200 条分批处理，并复用未变化的记录；旧批次不能覆盖新快照。构建期间保留已完成来源的结果并提示结果可能不完整；来源错误或无效记录显示错误，不覆盖项目内容。各来源撤销时取消其批次和订阅，会话关闭后不保留索引。搜索只读取各业务插件已提交的状态，不提交编辑表单或触发保存。

“刷新文件列表”调用工程管理已有刷新能力。当前没有统一文件系统监听；资产和时间线数据沿用所属插件的加载及错误处理，外部修改不会自动反映到搜索中。项目重新打开时重新建立内存索引，不产生索引文件。索引数据不是保存队列，不参与项目离开检查。
