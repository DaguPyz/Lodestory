# 项目搜索插件

项目搜索插件拥有项目会话内可重建的内存索引与搜索界面；不保存项目业务数据。工程管理、资产管理和时间线插件通过 `@lodestory/sdk/project-search` 分别登记来源，提供记录快照、变更订阅和打开操作。来源不暴露私有 store；工具栏通过公开事件请求打开搜索。

搜索工程树中 TXT 文稿的文件名、路径和正文，以及资产名称、说明及可见字段值，时间线与事件的名称和说明。正文结果按文稿分组，显示命中片段和行号。点击后打开文稿并选中对应文字。正文索引通过公开的工程目录、文档和编辑器契约建立，未保存的编辑内容优先于磁盘内容。

结果最多呈现 200 条；标题、说明和正文片段中的命中词使用主题搜索高亮色。打开事件结果进入所属时间线，暂不定位事件。名称及内容使用 NFKC 归一化和不区分大小写的子串匹配，中文可直接搜索。筛选、结果和错误均在当前会话内。文稿变更或打开结果时会校验当前内容；无法确认定位时提示重新搜索，避免跳到错误位置。

来源更新时索引按批处理，并复用未变化的记录。长正文搜索分段让出主线程，未打开的文稿按需读取。构建期间显示进度和已完成结果，来源错误或无效记录会显示提示。各来源撤销时取消其任务和订阅，会话关闭时释放索引。

“刷新文件列表”重新读取工程树及正文。当前没有统一文件系统监听；资产和时间线数据沿用所属插件的加载及错误处理，外部修改不会自动反映到搜索中。项目重新打开时重新建立内存索引，不产生索引文件。索引数据不是保存队列，不参与项目离开检查。
