# 设置插件

设置插件拥有应用级弹框与分类目录。欢迎页的设置入口通过导航布局的 `registerAction` 登记，工作台通过 SDK 的 `settingsKey.open()` 打开同一个弹框；两者都不切换 UI 页面或工作台会话。

插件在启动时可依赖 `settingsKey` 并调用 `registerSection({id, group, title, order, render})` 贡献自己的设置界面，在停用时调用返回的撤销函数。所贡献的组件和业务数据仍由贡献插件负责；当前分类登记在 UI 准备前完成，尚不承诺运行中安装或替换。设置插件负责撤销外层 UI 后释放自身资源。

内置主题和动效分类分别使用主题服务与配置服务，沿用它们各自的保存规则。动效保存失败和重试状态由应用级设置模型保留，切换分类或关闭弹框不会丢失；停用时等待已发起的写入结束。主题保存错误继续由主题服务管理。
