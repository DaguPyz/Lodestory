# 数值时间线插件

`timeline` 拥有时间线元信息、当前选择、数值轴设置和每条时间线的视口。`outline-design` 通过 `@lodestory/sdk/timeline` 展示导航列表并发出操作请求，不读取时间线私有实现。

## 数值与显示

- 世界坐标 `x = 0` 表示故事起点，显示数值由作者设置，不要求等于零。
- 作者设置起点数值、基础主刻度间隔和单位。默认是 `0`、`5`、`天`；单位是自定义文字，不自动转换历法或时间单位。
- 左侧数值按间隔递减，右侧递增。例如起点 `100`、间隔 `5` 时为 `…90、95、100、105、110…`。
- 缩放调整可见刻度密度，数值与世界坐标的映射保持不变；仅绘制可见范围内的刻度，文字保持屏幕阅读尺寸。原点在视野内时标为“故事起点”。
- 纯色底、水平轴线、主次刻度、数字及单位使用共享主题变量。点击单位文字修改当前时间线配置；画布操作复用通用 `canvas`。

## 插件协作

提供 `timelineKey`；依赖 `layoutKey`、`workbenchKey`、`projectStorageKey` 和 `canvasKey`。主内容通过 `layout.registerContent` 登记，默认实现由 `appPlugins` 静态装配；内核和入口不编排时间线业务。

公开服务按项目会话返回列表模型，并提供打开时间线操作。模型快照是唯一的选择来源；大纲不另存选中 ID，也不创建视口。公开契约不暴露存储适配器或第三方实例。

## 存储与生命周期

列表继续使用 `.lodestory/outline-design/timelines/<uuid>.json` 的既有七字段格式；目录名称出于兼容保留，读写所有权迁入本插件。

横轴设置独立保存于 `.lodestory/timeline/axes/<uuid>.json`。无设置文件的旧时间线使用默认值，首次修改时创建文件。项目存储统一管理字节缓冲、保存队列、自动保存与冲突检查；本插件只解释自己的 UTF-8 JSON，不创建另一套保存定时器。

读取失败或格式损坏时保留原始内容并提示错误；保存失败保留编辑值和重试入口。未提交的创建/设置表单参与工作台离开检查。每个项目会话分别管理模型、轴设置订阅和视口；隐藏后保留，结束或停用时先停止 UI 使用，再释放资源。视口位置只在会话内保留。

删除元信息后，关联设置文件暂时保留，不把两个非事务文件操作伪装为原子删除；新时间线使用新 UUID，不会复用旧设置。

当前范围只包含数值横轴，不含事件卡片、人物地点、历法解析或单位换算。
