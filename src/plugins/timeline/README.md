# 数值时间线插件

`timeline` 拥有时间线元信息、事件数据、当前选择、数值轴设置和每条时间线的视口。`outline-design` 通过 `@lodestory/sdk/timeline` 展示导航列表并发出操作请求，不读取时间线私有实现。

## 数值与显示

- 世界坐标 `x = 0` 表示故事起点，显示数值由作者设置，不要求等于零。
- 作者设置起点数值、基础主刻度间隔和单位。默认是 `0`、`5`、`天`；单位是自定义文字，不自动转换历法或时间单位。
- 左侧数值按间隔递减，右侧递增。例如起点 `100`、间隔 `5` 时为 `…90、95、100、105、110…`。
- 缩放调整可见刻度密度，数值与世界坐标的映射保持不变；仅绘制可见范围内的刻度，文字保持屏幕阅读尺寸。原点在视野内时标为“故事起点”。
- 纯色底、水平轴线、主次刻度、数字及单位使用共享主题变量。点击单位文字修改当前时间线配置；画布操作复用通用 `canvas`。

## 事件节点

- 每条时间线可添加、编辑和删除事件。事件标题为 trim 后 1～60 个 Unicode 码点，摘要最多 200 个码点；摘要可空。`offset` 是距故事起点的数值增量，必须是有限数字且绝对值不超过 `1e9`；`placement` 为 `above` 或 `below`，`important` 标记关键事件。
- 事件标签显示 `origin + offset` 和当前轴单位。因此修改轴起点会同步更新事件的显示数值，事件保存的相对增量不变。当前不解析日历、时间范围或单位换算。
- 节点使用轴锚点、细引线和文字端点，不使用卡片或边框。普通事件在轴上显示圆点；关键事件在轴上显示琥珀色菱形。文字端点使用实心圆和外圆环，外环以 2.4 秒周期呼吸；内圆保持不动。时间线内容 inactive 时暂停外环，减少动效时外环静止。
- “关键转折”文字根据当前视口中的刻度文字、故事起点、事件文字和引线自动避让；优先在轴下方就近错开，底部空间不足时尝试轴上方。平移、缩放和窗口尺寸变化会重新计算，事件的时间数值与轴上锚点不变。
- 引线经过其他文字区域时留出空隙，避免密集节点的竖线穿过标题、摘要或轴刻度文字；同样适用于浅色和深色主题。
- 事件通过共享 Dialog 添加、编辑和删除。空项目不自动填入示例事件；保存失败时保留草稿并提供重试，未完成编辑参与工作台离开检查。
- 拖拽布局复用不可变事件快照的排序和字宽结果，通过视口范围检索候选节点；编辑产生新快照后重新建立索引。密集标签按实际横向区间回收可用车道，上下独立；转折说明使用 4px 横向桶与纵向区间并集保守避让，不按全量节点逐对扫描。时间线不再截取排序后的前 2048 个事件，后续事件移入视口后同样可以查看、编辑。
- 轴标记与穿过视口的引线保留；完全位于屏外的文字、端点和转折说明不挂载，移入视口时恢复。轴标记复用原生点击目标并整体平移，引线按普通／关键事件合并绘制，文字位置使用即时变换更新；时间数值与轴上锚点、悬停缩放、键盘操作、资产关联和存储格式保持原有规则。
- 刻度 SVG 按视口的屏幕尺寸绘制，并由包装层抵消画布缩放；数字保持 14px、起点说明保持 11px、普通线宽保持 1px。缩放仅重新投影位置和刻度间距，避免在 400% 时放大缩小后的 SVG 字体与线条。
- 事件编辑与新建表单支持关联多个资产。按资产类型模板筛选分类，再以名称或说明搜索；跨分类选择会保留在已关联列表，可逐项移除。未分类范围沿用资产管理规则，包含无类型或类型已归档的对象。关联仅随“保存事件”提交，取消不会修改事件。资产目录不可用、有错误或关联对象已删除时保留 ID；不可用对象会明确提示，可由作者移除。

## 插件协作

提供 `timelineKey`；依赖 `layoutKey`、`workbenchKey`、`projectStorageKey`、`canvasKey`、`contextMenuKey` 和 `assetCatalogKey`。主内容通过 `layout.registerContent` 登记，默认实现由 `appPlugins` 静态装配；内核和入口不编排时间线业务。

资产插件通过 `@lodestory/sdk/asset-catalog` 提供按项目会话隔离的只读目录。时间线只订阅公开的类型与资产摘要，不读取资产插件的私有 store，也不改写资产记录。关联 ID 归时间线事件所有；目录变更只更新显示名称和可选范围，不自动删除事件中的关联，也不阻止资产管理删除对象。

公开服务按项目会话返回列表模型，并提供打开时间线操作。模型快照是唯一的选择来源；大纲不另存选中 ID，也不创建视口。公开契约不暴露存储适配器或第三方实例。

## 存储与生命周期

列表继续使用 `.lodestory/outline-design/timelines/<uuid>.json` 的既有七字段格式；目录名称出于兼容保留，读写所有权迁入本插件。

横轴设置独立保存于 `.lodestory/timeline/axes/<uuid>.json`。无设置文件的旧时间线使用默认值，首次修改时创建文件。项目存储统一管理字节缓冲、保存队列、自动保存与冲突检查；本插件只解释自己的 UTF-8 JSON，不创建另一套保存定时器。

事件独立保存于 `.lodestory/timeline/events/<timelineId>.json`，格式标识为 `lodestory.timeline-events`、当前版本为 `2`。每个文件记录 `timelineId` 和事件数组；每个事件含 `id`、`title`、`summary`、`offset`、`placement`、`important` 及资产 ID 数组 `assetIds`。版本 1 的旧事件读取时补为空关联，不会仅因读取而写回；首次修改事件时升级到版本 2。关联只保存资产 ID，时间线不复制资产内容，也不会在资产被删除或归档时静默改写事件。事件数和时间范围由事件与轴设置派生，只用于列表快照，不写入既有七字段时间线元信息。列表条目删除后，轴设置和事件文件暂时保留，避免两个非事务文件操作造成数据丢失。

读取失败或格式损坏时保留原始内容并提示错误；保存失败保留编辑值和重试入口。未提交的创建/设置表单参与工作台离开检查。每个项目会话分别管理模型、轴设置订阅和视口；隐藏后保留，结束或停用时先停止 UI 使用，再释放资源。视口位置只在会话内保留。

删除元信息后，关联设置文件暂时保留，不把两个非事务文件操作伪装为原子删除；新时间线使用新 UUID，不会复用旧设置。

当前范围包含数值横轴、非卡片式事件节点和事件资产关联；不含事件卡片、历法解析、时间范围或单位换算。
