# 桌面版打包

## 构建当前平台安装包

准备好 Node.js 24、pnpm 8.10.2 和当前系统的开发依赖，再在仓库根目录运行以下命令。 [Tauri 环境准备](https://v2.tauri.app/start/prerequisites/)

```sh
pnpm install --frozen-lockfile
pnpm build:desktop
```

默认安装包输出目录为 `src-tauri/target/release/bundle/`。应用标识和打包版本见 [Tauri 配置](../src-tauri/tauri.conf.json)。

## 在 macOS 上构建 macOS 和 Windows 安装包

在 Mac 上安装 Windows 交叉编译工具并运行打包脚本。

```sh
brew install llvm lld nsis
cargo install --locked cargo-xwin
pnpm build:installers
```

只构建一个平台时，使用 `pnpm build:installers macos` 或 `pnpm build:installers windows`。首次构建 Windows 安装包时会下载 Windows SDK。

生成的安装包按平台归入 `output/installers.YYYYMMDDHHmmss/`，目录名使用构建开始时的本地时间。

| 平台 | 架构 | 安装包 |
| --- | --- | --- |
| macOS | Apple Silicon（ARM64） | `_aarch64.dmg` |
| macOS | Intel（x86‑64） | `_x64.dmg` |
| Windows | x64 | `_x64-setup.exe` |

## macOS 签名与公证

打包脚本默认对 macOS 应用和 DMG 签名。先将 **Developer ID Application** 证书及其私钥导入本机钥匙串。存在唯一可用证书时，脚本会自动选择。存在多个时，设置 `APPLE_SIGNING_IDENTITY` 为完整的签名身份名称。

使用临时签名构建测试包时，运行以下命令。

```sh
APPLE_SIGNING_IDENTITY=- pnpm build:installers macos
```

要在打包时提交 Apple 公证，在本机环境设置 `APPLE_API_KEY`、`APPLE_API_ISSUER` 和 `APPLE_API_KEY_PATH`，再运行以下命令。`APPLE_API_KEY_PATH` 指向仓库之外的 App Store Connect `.p8` 密钥文件。 [Tauri 签名与公证说明](https://v2.tauri.app/distribute/sign/macos/#notarization)

```sh
LODESTORY_MACOS_NOTARIZE=1 pnpm build:installers macos
```

## Windows 签名

Windows 安装包默认使用未签名构建。要启用签名，配置 Tauri 的 `signCommand` 后运行以下命令。 [Tauri 自定义签名命令](https://v2.tauri.app/distribute/sign/windows/#custom-sign-command)

```sh
LODESTORY_WINDOWS_SIGN=1 pnpm build:installers windows
```
