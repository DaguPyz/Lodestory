# 大纲设计

状态：核心设计思路已确认，功能尚未实现。本文记录产品方向与插件接入约束，具体数据结构和交互方案仍需细化。

## 功能定位

大纲用于梳理整个故事的脉络：以故事实际发生的时间为主轴，将一个个事件依次组织起来，并关联人物、地点、地图和世界设定。

**整个设计空间是一张以线性时间轴为主干、可以向外展开故事细节与世界设定的无限画布。**

大纲、人物、地点和地图的设计都围绕这一共同画布展开，逐步构建完整的故事与世界观。

## 已确认的设计原则

### 时间线是必需的主干

大纲按照故事实际发生的时间，由早到晚线性梳理。时间线是整个大纲的基础组织结构，不是可有可无的展示选项。

正文如何使用倒叙、插叙或其他叙事方式，由作者自行处理，不属于本功能的设计范围；大纲不另外维护正文的讲述顺序。

### 通过事件展开故事

时间线上的事件承载具体故事内容，围绕以下信息展开：

| 要素 | 回答的问题 |
| --- | --- |
| 时间 | 什么时候发生？ |
| 地点 | 在哪里发生？ |
| 人物 | 哪些人物参与？ |
| 事件内容 | 发生了什么？ |

这些信息帮助作者梳理和查找事件。是否必填、如何关联以及怎样标识同一事件，留待数据设计确定，本文不将四项信息的组合规定为唯一标识。

### 同一时刻允许多个事件并列

同一时刻，不同人物、不同地点可以发生不同事件。这些事件在相同时间位置并列呈现，不强行排列出不存在的先后关系；整个大纲仍沿时间向前推进。

例如，下表中的两个“第二天黎明”发生在同一时刻：

| 时间 | 事件 | 关联人物与地点 |
| --- | --- | --- |
| 第一天午后 | 王子被囚禁 | 王子、城堡 |
| 第二天黎明 | 主角调查王子的下落 | 主角、城内 |
| 第二天黎明 | 反派集结军队 | 反派、城外 |
| 第二天夜晚 | 主角展开营救 | 主角、王子、城堡 |

此例仅说明时间顺序与同时发生的关系，不规定时间字段的存储格式。

### 人物、地点与世界设定向外展开

作者可以围绕同一份大纲，从不同关联查看故事：

- 沿时间线，查看整个故事如何一步步发展。
- 展开一个事件，查看时间、地点、参与人物和具体内容。
- 沿人物关联，查看该人物经历了哪些事件。
- 沿地点关联，查看该地点发生过什么，并进一步展开地图及相关世界设定。

这些展开都围绕时间线组织，在同一无限画布中完成梳理与设计。画布提供向外展开的空间，同时保留故事的时间先后关系。

## 插件接入约束

以下是依据仓库架构原则确定的实现边界，不代表相应能力已经存在。

| 方面 | 约束 |
| --- | --- |
| 归属 | 扩展现有 `outline-design` 插件，由其负责大纲事件、时间组织及相关业务操作。人物、地点和地图资料由各自所属功能管理；具体是否拆分独立插件，按职责与替换需求另行确定。画布不包办各类资料的业务流程。 |
| 协作 | 复用 `layoutKey` 和 `workbenchKey`。跨插件访问人物、地点等资料时，由资料所属插件提供公开契约，大纲通过声明依赖使用；共享类型和 key 放入 SDK，不访问其他插件的私有状态。具体新契约待功能边界确定后补充。 |
| 接入 | 导航入口和画布工作内容通过布局服务的 `registerContent` 按用途登记，由布局决定呈现位置。默认实现通过配置或 `appPlugins.ts` 显式选择，入口不编排业务连接。 |
| 生命周期 | 大纲编辑资源随项目会话创建和释放，接入工作台统一离开检查。持久化内容、保存与冲突保护遵循文档插件的职责，具体存储和接入方案待定，不另建重复的保存定时器或退出流程。 |
| 验收 | 验证事件按实际时间排列、同时事件可并列、关联内容可在画布中展开；验证通过公开契约登记和协作，更换兼容实现无需修改消费者，并且不会影响正文编辑或丢失用户内容。 |

初始化失败时释放已创建的部分资源并撤销贡献；切换项目或停止插件前，先完成保存或明确保留未保存状态。保存失败时保留用户内容并阻止会丢失内容的离开操作。停止时先让组件结束对服务的使用，再释放订阅及其他资源。暂时离开工作台应保留项目会话中的编辑状态。

## 当前实现状态

现有 [`outline-design`](../../src/plugins/outline-design/outlineDesignPlugin.tsx) 插件只贡献“大纲设计”导航入口与面板，依赖布局和工作台服务；[面板](../../src/plugins/outline-design/OutlineDesignPanel.tsx)仅显示用途说明与当前项目。

目前没有大纲数据、时间线、无限画布或对应编辑操作。本文描述的是后续目标，也不意味着应用已经支持运行中任意安装或卸载这些功能插件。

## 后续需要细化的内容

- 时间如何表达，包括精确时间、相对先后、时间范围及尚未确定的时间。
- 事件的粒度、标识，以及事件与人物、地点之间的关联规则。
- 人物、地点、地图与世界设定在画布中的编辑范围、展开和收起方式。
- 画布导航、缩放与定位方式，以及画布位置和事件时间的操作关系。
- 数据存储、保存恢复、跨插件契约和具体插件划分。
