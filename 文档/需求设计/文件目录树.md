# 文件目录树与新建文档

当前文件树 UI、目录列表 API、目录选择与新建文档对话框由独立的[工程管理插件](工程管理插件.md)实现；documents 管理打开文档和新建流程，正文文件缓冲与保存由[项目存储插件](项目存储插件.md)提供。本文记录用户可见行为和文件边界；布局位置由布局插件决定。

## 新建文档

点击作品文件面板右上角的“＋”，输入文档名称并选择作品内的保存目录。未填写受支持的后缀时自动追加 `.md`；也支持 `.markdown` 和 `.txt`。

创建的是磁盘上的 UTF-8 文本文档。创建成功后展开所在目录、选中新文档并打开编辑标签，焦点进入正文。同名文件或目录不允许覆盖；失败时保留输入和错误提示，取消不创建文件。

默认保存到最近选中的目录，或最近打开文档所在目录；初始位置为作品根目录。当前只提供新建文档，不提供新建目录、重命名或删除入口。

## 目录浏览

进入作品时递归读取真实目录，以文件夹优先、名称排序的方式显示 Markdown 和纯文本文件。文件夹可展开、折叠；点击文档打开或切换标签。忽略隐藏文件、隐藏目录及符号链接，避免遍历 Git 数据或目录循环。

所有文件操作使用作品根目录与相对路径；校验名称、路径分隔符、系统保留名称、目录穿越，以及解析后的路径是否仍在当前作品内。

## 右键菜单规划

目录条目、文档条目和目录树空白处已分别接入[全局右键菜单](全局右键菜单.md)。目录菜单提供新建文档与展开或折叠，文档菜单提供打开，空白处提供在作品根目录新建文档。动作针对右键命中的对象，并复用现有路径校验与新建流程。

## 编辑与保存

正文使用纯文本编辑，支持浏览器原生输入、复制、粘贴、撤销和重做。停止输入 700ms 后由项目存储自动保存，也支持 `Cmd/Ctrl+S` 经 documents workspace 请求保存。标签和底部状态栏显示项目存储快照派生的真实保存状态，字数按非空白字符统计。

同一文档的写入串行执行，保留保存期间的新修改。后端使用同目录临时文件原子替换，并保留文件权限；保存前核对上次读取的内容，发现外部修改或文件被删除时阻止覆盖或重建。

关闭标签、返回欢迎页、进入设置和正常关闭窗口前等待保存。保存失败时保留正文、显示错误与重试入口，并阻止关闭标签或离开当前工作空间。强制终止进程后的草稿恢复、完整 Markdown 排版、外部文件变化监听和重新启动后的标签恢复尚未实现。

## 接口与验证

| Rust 命令 | 功能 |
| --- | --- |
| `list_documents` | 读取作品目录树 |

宿主仅保留 `list_documents` 供工程管理插件读取文件树；正文的新建、读取、保存与删除由 documents workspace 通过项目存储的通用字节文件接口处理，目录创建由项目存储接口处理。通用接口按调用方提供的完整相对路径传递字节，不决定 UTF-8 编码或文件格式；现有项目文件的名称、内容与位置不因此迁移或改写。文件树筛选隐藏项、支持的文档扩展名、目录优先排序及跳过符号链接仍由 `list_documents` 实现。

Rust 自动检查分别覆盖文件树的筛选、递归排序和符号链接处理，以及项目存储的字节文件读写、目录操作、路径安全、只读权限与 expected-bytes 冲突保护。前端自动检查覆盖自动保存、保存期间编辑、撤销、失败重试及离开前保存。

[开发专用测试页面](../../tests/fixtures/project-index.html)通过 Tauri IPC mock 检查对话框、重名提示、子目录创建、自动展开、编辑、重新打开及保存失败时保留正文；`?scenario=create-error`、`?scenario=save-error`、`?scenario=slow-save` 提供相应场景，不修改真实作品文件。多平台原生窗口关闭与中文输入法的完整验收仍需分别验证。
