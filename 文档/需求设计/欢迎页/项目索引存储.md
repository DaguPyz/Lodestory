# 项目索引存储

欢迎页最近项目列表使用本机用户级索引；已替换写死的示例数据。

## 存储位置

通过 Rust 后端的 `app.path().app_config_dir()` 获取配置目录，再追加 `recent-projects.json`。在 `tauri.conf.json` 中将配置目录覆盖为 `$CONFIG/Lodestory`；应用标识沿用 `com.lodestory.app`。

| 系统 | 默认路径 |
| --- | --- |
| macOS | `~/Library/Application Support/Lodestory/recent-projects.json` |
| Windows | `%APPDATA%\Lodestory\recent-projects.json` |
| Linux | `~/.config/Lodestory/recent-projects.json`；设置 `XDG_CONFIG_HOME` 时采用该目录 |

路径由 Tauri 解析，遵循系统配置；不硬编码用户名。参见 [Tauri 路径规则](https://v2.tauri.app/reference/javascript/api/namespacepath/#appconfigdir)。

启动时，若新配置目录尚不存在且旧的 `com.lodestory.app` 目录存在，将整个旧目录重命名为 `Lodestory`，保留原索引及其他配置文件。若新旧目录同时存在，以新目录为准，旧目录保留且不覆盖任何文件；迁移失败时报告错误。

索引首次成功登记项目时创建，启动时不存在则返回空列表。索引独立于小说目录和应用安装目录。

## 文件结构

```json
{
  "schemaVersion": 1,
  "projects": [
    {
      "id": "66c64727-ddb5-4bd6-b8cc-b029b57bde2c",
      "name": "长夜行舟",
      "path": "/Users/writer/Novels/长夜行舟",
      "lastOpenedAt": "2026-09-29T01:41:00Z"
    }
  ]
}
```

| 字段 | 约定 |
| --- | --- |
| `schemaVersion` | 当前为 1，后续结构变化通过版本迁移处理 |
| `id` | 首次登记生成 UUID v4；重复打开、重新定位保留 ID |
| `name` | 项目目录名称；重新打开或定位后更新 |
| `path` | 规范化的绝对路径，解析符号链接；Windows 采用普通路径形式 |
| `lastOpenedAt` | 最近成功创建、打开或重新定位的 UTC 时间，使用 RFC 3339 格式 |

响应中的 `available` 在读取时检测目录是否可访问，不写入索引。界面按本地时间显示“今天”“昨天”或日期，列表按最近打开时间倒序排列。

## 更新与异常处理

- 打开目录：先检查目录类型和读取权限，再登记；规范化路径相同或指向同一物理目录的项目只保留一条，包括大小写不敏感文件系统上的别名。
- 新建项目：输入小说名称、选择父目录，创建同名目录后登记；同名路径已存在时拒绝覆盖。名称检查拒绝路径穿越、特殊字符及系统保留名称。
- 重新定位：选择已有目录，更新原记录并打开；目标已被登记时合并记录，保留被重新定位项目的 ID。原目录和文件不受影响。
- 移除：只删除索引条目，不删除项目目录或文件。
- 目录不可访问：保留索引，显示“目录不可用”，可重新定位或移除；返回欢迎页时重新检测。
- 写入：Rust 后端统一处理；同一应用进程的操作通过互斥锁串行执行，每次更新前重读索引。同目录临时文件写完并同步后原子替换，失败时保留原索引。
- 文件损坏、记录结构无效或版本不支持：返回明确错误，保留原文件并阻止索引更新，允许修复后刷新。
- 新建目录成功但索引保存失败：保留新建目录，错误提示显示目录路径，用户可通过“打开目录”重试。

## 当前范围与验证

欢迎页接通原生目录选择、新建、打开、搜索、移除、重新定位和空列表/错误状态。浏览器预览不伪造索引，项目目录操作仅在桌面应用中提供。

项目目录浏览、新建文档、正文读写及基础自动保存已接通，参见[文件目录树与新建文档](../文件目录树.md)；自动恢复工作状态仍待实现。真实项目进入编辑工作空间，不显示无关示例文稿。

Rust 测试覆盖文件结构与重启读取、去重、排序、并发写入、目录丢失与重新定位、移除不删文件、无效名称、不覆盖已有目录、损坏/未知版本保护和原子替换失败。前端测试覆盖本地日期显示及 Windows/macOS/Linux 路径显示。

界面走查使用 [开发专用 IPC 测试页面](../../../tests/fixtures/project-index.html) 和 Tauri 官方 mock，覆盖新建表单、创建后进入项目、搜索、移除、重新定位、损坏提示及取消目录选择；该测试页面不修改实际目录或索引，不包含在生产入口中。原生目录选择器与 Windows/Linux 运行验收尚未验证。
