# 正文编辑插件

## 定位与边界

`body-editor` 提供工作台的正文编辑界面，包括正文输入、空态和保存反馈。文稿标签由 `document-tabs` 提供，写作状态由 `writing-status` 提供。三个插件分别依赖工作台、文档与布局 SDK 服务，不向其他插件提供服务 key；正文字符串和保存状态来自 `documents` workspace，底层共享字节缓冲由项目存储管理。

插件声明如下：

```ts
{
  id: "body-editor",
  requires: [workbenchKey, documentsKey, layoutKey],
  provides: [],
}
```

正文插件私有的 React Context 和会话视图模型只供自身组件使用。其他插件通过 SDK 的 `documentsKey`、`layoutKey`、`workbenchKey` 和文档事件协作，不导入正文插件内部模块。

## 提供的内容

| 内容 | 行为 |
| --- | --- |
| `body-editor.main` | 显示当前正文，或没有打开文档时的新建入口；提供保存失败重试。 |

`document-tabs` 独立登记 `document-tabs.tabs`（`tabs`），提供已打开文稿的切换、保存、关闭和新建入口。`writing-status` 独立登记 `writing-status.status`（`status`），显示当前文稿保存状态、字符数与基础阅读信息。两者都直接读取 documents workspace，不依赖正文插件的私有 Context 或组件。

正文输入首版继续使用受控 `textarea`，沿用浏览器原生编辑菜单。`writing-status` 当前按非空白字符计数，Markdown 标记也计入；它不代表纯正文词数。documents workspace 将项目存储中的内容、保存状态和错误映射到打开文档快照，供正文和状态插件读取。

正文插件把 main 登记到布局服务，布局决定展示位置和可见状态。插件只在 main 内容中安装正文快捷键；布局传入的 `active` 为 false 时停止快捷键和临时交互。切换标签使用隐藏非当前文稿的方式保留已挂载输入框及其本地编辑状态。标签和状态内容由各自插件登记，可独立显示、隐藏和撤销。

## 文档工作区接入

文档插件为每个工作台会话创建 documents workspace 后，正文插件的参与者通过 `documents.getWorkspace(session.id)` 取得该会话的同一个工作区，并在会话期间订阅快照。正文插件本地模型只保存当前会话需要的视图信息和工作区句柄，不复制文档正文或当前选择。

正文和标签插件通过 workspace 快照显示文稿。编辑调用 `workspace.update(id, content)`，切换标签调用 `workspace.select(id)`，关闭调用 `workspace.close(id)`，手动保存调用 `workspace.save(id)`；正文快捷键调用 `workspace.saveAll()`。这些文档操作由 documents 管理，实际缓冲、自动保存、写入串行化和冲突保护由 project-storage 执行；离开项目时由工作台协调两者检查，project-storage 负责共享内容落盘。`busy` 或 workspace 的 `blocked` 为 true 时，正文设为只读并停用保存快捷键；已接受的保存仍会继续完成。

正文空态和标签栏的新建入口发送 `documentCreateRequested({sessionId, parentPath?})`。工程管理插件确认当前会话后展示自己的新建对话框，并在用户确认后调用 `workspace.create`；正文插件不直接依赖工程管理组件。

## 文档显示与恢复焦点

文档服务在打开或创建文档成功，以及离开检查保存失败需要定位正文时发送 `documentRevealRequested({sessionId, documentId})`。正文插件依次核对事件会话仍是工作台当前会话，以及该文档仍存在并仍是 workspace 的 `activeId`。通过检查后调用 `layout.show("body-editor.main")`，并更新本地 reveal 版本。

显示与聚焦分开执行：收到有效请求时，即使工作台忙碌、文档 workspace 被阻塞或 main 当前隐藏，也先展示正文，使保存错误可见；等 main 为 active 且工作台不 busy、workspace 不 blocked 后再恢复焦点。reveal 版本让阻塞期间的请求在状态恢复后仍触发聚焦。

## 生命周期

- 隐藏正文或切换标签时保留编辑实例；正文组件根据布局的 `active` 暂停快捷键。
- 离开检查期间，正文只读；documents 完成已接受的文档操作，project-storage 保存共享缓冲。检查失败后保留当前会话、正文和错误重试入口。
- 真正关闭或切换项目时，工作台释放正文插件的会话参与者；正文插件清理本地模型和订阅。documents 清理打开项与选择，project-storage 清理共享缓冲、保存队列和定时器。
- 正文插件停用时撤销 `body-editor.main` 登记，并撤销工作台参与者；标签和状态插件分别撤销自己的布局内容。

## 与其他编辑功能的边界

`document-tabs` 提供文稿标签，`writing-status` 提供写作状态；两者通过 documents workspace 协作，不依赖 `body-editor`。`workbench-toolbar` 提供项目操作栏、设置入口、顶部布局操作与专注模式，登记 actions 内容；专注模式通过布局已有的 `show/hide` 能力切换导航和辅助内容，状态由工具栏按工作台会话保存。它不保存文档，也不执行离开检查。工程文件树与新建文档对话框由 [`工程管理插件`](工程管理插件.md) 提供，布局排列和通用显隐由 [`布局插件`](布局插件.md) 管理。参考资料功能尚未实现，形式待后续设计。

本次正文插件保留 `textarea`，不新增 `editorKey`，也不接入 Quill 或 Milkdown。富文本和 Markdown 格式适配器仍是[后续编辑器替换方案](编辑器插件化集成方案.md)；当前设计不承诺异常退出后的崩溃恢复。

正文实现位于 `src/plugins/body-editor/`，包括 `bodyEditorPlugin.tsx`、`bodyEditorModel.ts`、`BodyEditorContext.tsx`、`BodyEditorView.tsx`、`Manuscript.tsx`、`useDocumentWorkspace.ts`、内容 ID 定义与样式；标签实现位于 `src/plugins/document-tabs/`，写作状态实现位于 `src/plugins/writing-status/`。
