# 编辑功能

## 功能定位

面向小说作者，支持在项目工作空间内编辑章节和资料文件。

Quill 富文本编辑器与 Milkdown Crepe Markdown 编辑器的接入边界、存储格式和验收要求见[编辑器插件化集成方案](编辑器插件化集成方案.md)。

编辑功能在工作台打开项目时按会话创建资源，并参与统一离开检查：切换项目、关闭项目或关闭应用前完成保存检查；暂时进入设置页时保留编辑会话。离开检查期间阻止新的编辑输入，但已有保存继续完成。协议与导航入口见[工作台插件设计](工作台插件.md)。

## 初步功能规划

| 功能 | 需求说明 |
| --- | --- |
| 多文件标签页 | 同时打开多个章节或资料，通过标签页快速切换。 |
| 正文编辑 | 支持输入、复制、粘贴、撤销、重做，以及中文段落首行缩进。 |
| 自动保存 | 自动保存修改，显示保存状态；异常退出后尽可能恢复未保存内容。 |
| 查找与替换 | 在当前文件中查找文字，支持批量替换。 |
| 字数统计 | 显示当前章节字数及选中文字的字数。 |
| 阅读与排版设置 | 支持调整字体、字号、行距、正文宽度和背景，适应长时间写作。 |
| 分屏参照 | 编辑正文时，可同时查看其他章节、人物设定或大纲。 |
| 专注模式 | 隐藏目录树等辅助区域，只保留正文编辑区。 |
| 右键菜单 | 已按文档标签、空白区域及文稿区域提供对应操作，正文输入首期保留原生编辑菜单；实现与验收记录见[全局右键菜单](全局右键菜单.md)。 |
