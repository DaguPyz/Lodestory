# 编辑功能

## 功能定位

面向小说作者，支持在项目工作空间内编辑章节和资料文件。

正文宿主通过 SDK 加载 TXT 编辑器。标签栏由独立插件提供，正文空态与保存反馈由宿主提供。接入方式见[编辑器插件化集成方案](编辑器插件化集成方案.md)。

正文编辑插件在打开项目时按会话创建视图模型；documents 管理打开项、选择与编辑工作区的文档操作，project-storage 持有正文共享缓冲并负责自动保存、冲突保护和项目离开时的落盘。暂时进入设置页时保留编辑会话，离开检查期间正文只读而已接受的保存继续完成。协议与导航入口见[工作台插件设计](工作台插件.md)。

## 初步功能规划

| 功能 | 需求说明 |
| --- | --- |
| 多文件标签页 | 同时打开多个章节或资料，通过标签页快速切换。 |
| 正文编辑 | 支持输入、复制、粘贴、撤销、重做，以及中文段落首行缩进。 |
| 自动保存 | 正文将字符串更新交给 documents 适配层编码为字节，再写入项目存储的共享缓冲并自动保存；正文与标签从 documents workspace 显示保存状态。异常退出后恢复未保存内容仍是后续目标，当前不提供崩溃恢复。 |
| 查找与替换 | 在当前文件中查找文字，支持批量替换。 |
| 字数统计 | 显示当前章节字数及选中文字的字数。 |
| 阅读与排版设置 | 支持调整字体、字号、行距、正文宽度和背景，适应长时间写作。 |
| 分屏参照 | 编辑正文时，可同时查看其他章节、人物设定或大纲。 |
| 专注模式 | 工作台工具栏组合布局的通用显隐能力，暂时隐藏已显示的目录树等导航/辅助内容，并可恢复原显示选择。 |
| 右键菜单 | 已按文档标签、空白区域及文稿区域提供对应操作，正文输入首期保留原生编辑菜单；实现与验收记录见[全局右键菜单](全局右键菜单.md)。 |
