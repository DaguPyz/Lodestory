# 页面骨架与启动流程

## 设计定位

参考 IntelliJ IDEA 的项目入口方式，采用「欢迎页 → 创建或打开项目 → 项目工作台」的整体结构。

一个项目对应一部小说，一部小说对应一个目录；打开该目录，即进入该小说的工作空间。

本文为初步规划，具体交互后续逐项细化。

编辑页面由工作台插件协调项目会话和页面生命周期，布局已抽成独立插件，功能内容按用途登记。接口与生命周期见[工作台插件设计](工作台插件.md)和[布局插件设计](布局插件.md)。下述区域描述是默认视觉方案，不是功能插件必须使用的固定位置。

## 页面组成

| 页面 | 功能 |
| --- | --- |
| 欢迎页 | 展示最近项目，提供「新建项目」「打开目录」「设置」入口。 |
| 新建项目对话框 | 填写小说名称、选择保存位置，创建对应目录。 |
| 项目工作台 | 围绕当前小说目录，进行文件管理、编辑和版本管理。 |

## 项目工作台骨架

| 区域 | 内容 |
| --- | --- |
| 顶部 | 项目名称、项目切换、常用操作。 |
| 左侧工具栏与面板 | 切换文件目录树、版本管理。 |
| 中央编辑区 | 文件标签页、正文编辑，支持分屏。 |
| 底部状态栏 | 字数、保存状态等。 |

## 全局右键菜单

欢迎页与项目工作台复用统一菜单组件，各区域根据右键目标提供菜单项和业务上下文。区域识别、首期菜单、嵌套优先级、原生编辑行为及验收规则见[全局右键菜单](全局右键菜单.md)。

## 启动与进入流程

### 首次启动

进入欢迎页，新建项目或打开已有目录，加载后进入项目工作台。

### 再次启动

首个页面由配置项 `ui.initialPage` 决定；首版配置为 `welcome`，所以目前首次和再次启动都进入欢迎页。自动恢复上次项目、已打开文件和编辑位置是后续目标，恢复开关接入前不会自动打开项目。

配置由独立配置插件提供。UI 在所有页面登记后读取启动页配置；运行中修改该项只影响下次启动。配置协议、默认值、存储优先级和范围见[配置插件设计](配置插件.md)。

### 无法恢复项目

例如项目目录已移动，提示原因并返回欢迎页。

### 关闭项目与退出软件

- 关闭项目：通过工作台统一离开检查；所有参与者允许后释放项目会话并返回欢迎页，被阻止时仍留在当前项目。
- 暂时进入设置等页面：执行 `suspend` 检查并保留工作台会话；返回时恢复原会话。
- 退出软件：拦截窗口关闭请求并执行 `shutdown` 检查；所有参与者允许后释放项目会话并关闭，工作状态记录供下次启动恢复。

工作台会话和参与者协议见[工作台插件设计](工作台插件.md)。UI 的 `open`、`back`、同页项目替换和关闭窗口均须经过统一的异步检查。`app` 只装配插件；启动页通过配置服务交给 UI 插件读取。
